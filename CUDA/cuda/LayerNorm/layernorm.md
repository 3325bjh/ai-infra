# Layer Normalization 公式

## 1. 基本定义

对于输入向量 x = (x₁, x₂, ..., x_H)，其中 H 是特征维度：

### 均值计算
μ = (1/H) * Σᵢ₌₁ᴴ xᵢ

### 方差计算
σ² = (1/H) * Σᵢ₌₁ᴴ (xᵢ - μ)²

### 归一化
x̂ᵢ = (xᵢ - μ) / √(σ² + ε)

### 缩放和平移
yᵢ = γ * x̂ᵢ + β


## 2. 完整公式

LayerNorm(x) = γ ⊙ (x - μ) / √(σ² + ε) + β

其中：
- ⊙ 表示逐元素乘法
- γ 是缩放参数（可学习）
- β 是偏移参数（可学习）
- ε 是防止除零的小常数（通常 1e-5 或 1e-6）
